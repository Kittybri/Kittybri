# Abriana Meazzo

I build and maintain AI-assisted conversational applications. My current projects, **Scaramouche** and **Wanderer**, use Discord as an interface for persistent conversation, voice, media, and creative interactions.

My background includes business and finance studies. My engineering work focuses on turning concrete user problems into clear requirements, reproducible failures, bounded repairs, and tests that explain whether a fix worked.

## How I work

These projects use AI coding agents. I supply project direction, requirements, observed failures, and constraints; agents assist with implementation, diagnostics, tests, and documentation. The [contribution statement](https://github.com/Kittybri/agent-repair-lab/blob/main/CONTRIBUTIONS.md) describes those boundaries. I do not claim unaided authorship of every line or unmeasured performance results.

Current interests: conversational systems, evaluation-task design, reliable integrations, and learning to make engineering decisions easier to inspect and reproduce.
